Group Snooze — Privacy Policy

Last updated: 23 August 2026

Group Snooze does not collect, transmit, sell or share any data. There is no server, no analytics, and no network request of any kind. Everything described below stays inside your own browser profile.

What the extension stores

Two things, both in chrome.storage.local on your own machine:

  • Tab group records — the title, colour and auto-pause preference of each titled tab group, so it can remember which groups you opted out of.
  • Page snapshots — captured only if you grant optional access to all sites, and only in the instant before a tab is discarded.

What a snapshot contains

  • The playback position and paused state of <video> and <audio> elements.
  • The values of form fields, so typing is not lost when the tab reloads.

What is never captured

  • input[type=password]
  • input[type=hidden] and file inputs
  • Payment fields — any autocomplete value starting with cc-
  • autocomplete="one-time-code" fields
  • Any field in a form marked autocomplete="off", and any field marked autocomplete="off" itself
  • Page content, browsing history, cookies, and anything on a page that was not discarded

How long snapshots last

A snapshot exists only for the window between a tab being discarded and that tab being restored. It is deleted as soon as it is replayed, and also if the reloaded tab's URL no longer matches the captured one, if the tab is closed, or after 24 hours — whichever comes first. Clearing everything at any time is a single button on the options page.

Permissions and why they are needed

  • tabs, tabGroups — detect a group being collapsed and find its tabs.
  • scripting — inject the one-shot capture and restore functions.
  • storage — keep group preferences and pending snapshots locally.
  • contextMenus — the tab right-click entries.
  • <all_urls> — optional, off by default, requested only from the options page. Used solely for the capture and restore described above. Without it the extension still discards collapsed groups; it just cannot restore media position or form input.
