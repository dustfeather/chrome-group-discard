Group Snooze

Snapshot access

Group Snooze discards collapsed groups without any host access. Granting access to all sites additionally lets it capture media position and form input immediately before a tab is discarded, and replay it when the tab comes back. Everything stays in local storage. Passwords, hidden fields, payment (cc-*) and one-time-code fields are never read.
